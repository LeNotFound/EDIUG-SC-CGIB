# 纯纯的 SB

    你说的对，但“请不要动不动就过来找我”。

    作为一个辅导员，做不到为每个学生答疑解惑能够理解，但学生遇到问题、遇到纠纷，没有一个正确的解决方式，最后把问题抛给学生，说学生不应该来找她，是做和心理？不来找辅导员那学生的问题应该去找谁，至少应该有个指向，而不是把问题推走不管。

    和她关系好的学生说她人好，但有没有想过这个学院也存在着除了班干部以外的其他人，对于班干部这种本身就不缺少信息差的群体，相比之下普通学生有时才更需要辅导员的帮助吧。
